CLASS PROGRAM

반은 아이의 성장 단계와 수업 목표에 맞춰 나뉩니다.

각 반은 다음 단계로 넘어가기 위한 몸의 준비, 기술 준비, 작품 준비가 다릅니다.

01

유아반

대근육 기반 움직임, 리듬감과 균형감을 수업 적응과 함께 만드는 입문 단계입니다.

Active Start
02

초급반

줄넘기, 점프운동, 스트레칭, 코어 기본 자세와 여러 기구의 조작을 익힙니다.

FUNdamentals
03

중급반

기술 연결, 점프와 턴, 기구 조작을 작품 흐름 안으로 연결합니다.

Learn to Train
04

대회반

음악 해석, 작품 완성도, 무대 경험, 경기 루틴을 다룹니다.

Learn to Compete
05

선수 준비반

훈련량, 컨디셔닝, 작품 관리, 대회 목표를 장기 계획으로 연결합니다.

Learn to Win
